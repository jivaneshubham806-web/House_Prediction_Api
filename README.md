# 🏠 California House Price Prediction API

A machine learning REST API that predicts house prices in California. A **Random Forest Regressor** is trained on the scikit-learn California Housing dataset and served with **FastAPI**. You can predict a single house with JSON, or upload a CSV file to predict many houses at once.

## ✨ Features

- Random Forest model trained on the California Housing dataset
- `POST /predict` – predict the price of one house
- `POST /predict_file` – upload a CSV and download a CSV with predictions
- Input validation with Pydantic (e.g. latitude/longitude must be inside California)
- Automatic interactive docs (Swagger UI) at `/docs`

## 📊 Model Performance

| Metric | Value |
|--------|-------|
| Model | RandomForestRegressor (100 trees) |
| Train/Test split | 80% / 20% (`random_state=42`) |
| Average error (MAE) | ~ $35,000 |

> Run `python train.py` to see the exact MAE printed for your run.

## 🚀 Usage

### 1. (Optional) Explore the data
```bash
python explore.py
```

### 2. Train the model
```bash
python train.py
```
This creates `house_model.joblib` and `house_features.joblib`.

### 3. Start the API
```bash
uvicorn main:app --reload
```
Open **http://127.0.0.1:8000/docs** to try the API in your browser.

## 📡 API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/` | Welcome message and API status |
| GET | `/health` | Health check and model info |
| POST | `/predict` | Predict price for a single house |
| POST | `/predict_file` | Predict prices for a CSV file |

### Input features

| Feature | Description | Validation |
|---------|-------------|------------|
| `MedInc` | Median income in the block group (in $10,000s) | > 0 |
| `HouseAge` | Average age of houses | > 0 |
| `AveRooms` | Average number of rooms per household | > 0 |
| `AveBedrms` | Average number of bedrooms per household | > 0 |
| `Population` | Block group population | > 0 |
| `AveOccup` | Average number of household members | > 0 |
| `Latitude` | Block group latitude | 32 – 42 |
| `Longitude` | Block group longitude | -124 – -114 |

### Example: single prediction

**Request**
```bash
curl -X POST "http://127.0.0.1:8000/predict" \
  -H "Content-Type: application/json" \
  -d '{
    "MedInc": 8.3252,
    "HouseAge": 41,
    "AveRooms": 6.98,
    "AveBedrms": 1.02,
    "Population": 322,
    "AveOccup": 2.55,
    "Latitude": 37.88,
    "Longitude": -122.23
  }'
```

**Response** (values will vary)
```json
{
  "predicted_price": "$425,000",
  "predicted_price_float": "425000.00",
  "Fidence_range": "$390,000 - $460,000"
}
```

### Example: CSV prediction

Your CSV must contain these columns:
`MedInc, HouseAge, AveRooms, AveBedrms, Population, AveOccup, Latitude, Longitude`

```bash
curl -X POST "http://127.0.0.1:8000/predict_file" \
  -F "file=@houses.csv" \
  -o predictions.csv
```
The returned `predictions.csv` has an extra `predicted_price_usd` column.

## ⚠️ Limitations

- The dataset is from the **1990 California census**, so predicted prices are far below today's real market prices. This project is for learning/demo purposes only.
- The `±$35,000` range is an approximate average error, not a statistical confidence interval.
